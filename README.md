# Gaze Knit Studio

A creative design tool for transforming eye-tracking data into computational textiles.

## Features

- Layer-based gaze visualizations and textile styling
- Heatmaps, scanpaths, and temporal patterns
- Custom yarn palettes and pattern composition
- PNG stitch-chart and JSON design export

## Fabrication

Import the exported PNG into Customist Studio and configure yarn carriers, stitch structure, cast-on, bind-off, and machine validation before knitting on Kniterate. This is a research prototype; physical fabrication has not yet been validated.

Data is processed locally in the browser.
